# 环境切换与本地联调

## 目的

把“数据环境”和“连接方式”分开，并通过项目工具固定切换路径。只要目标是本地开发，无论模拟器、同局域网真机还是非局域网真机，最终数据环境都必须保持 `thyroid_local`；手机只访问本机服务端 API，不直接连接 MySQL。

公共脚本位于 `tools/env/`；机器私有值只写入被 Git 忽略的 `tools/env/local.env.ps1`。真实局域网地址、密码、密钥、Token、第三方工具二进制和临时隧道状态不得提交。

## 固定入口

| 目的 | 命令 | 数据目标 |
| --- | --- | --- |
| 查看当前状态 | `& '.\tools\env\manage.ps1' -Status` | 只读本机状态 |
| 模拟器 | `& '.\tools\env\manage.ps1' -Mode Simulator` | `thyroid_local` |
| 同局域网真机 | `& '.\tools\env\manage.ps1' -Mode Lan` | `thyroid_local` |
| 非局域网真机 | `& '.\tools\env\manage.ps1' -Mode Remote -ConfirmRemoteTunnel` | `thyroid_local` |
| 停止非局域网通道 | `& '.\tools\env\manage.ps1' -StopRemote` | 恢复模拟器模式 |
| 生产 API | `& '.\tools\env\manage.ps1' -Mode Production -ConfirmProduction` | 仅切客户端生产 API |

`manage.ps1` 直接读取当前 `api.ts`、私有开发者工具配置和本机环境配置，不维护第二份“当前模式”标记。状态输出只显示环境身份、布尔配置和健康状态，不输出秘密或真实地址。

本机服务独立使用 `tools/env/start-local-server.ps1`；新建空本地库才使用 `tools/env/import-migrations.ps1 -ConfirmEmptyDatabase`。

## 本地模拟器

目标状态：

```text
小程序：LOCAL / localhost
服务端：本机回环监听
数据库：thyroid_local
开发者工具：urlCheck=false
```

推荐顺序：

1. `manage.ps1 -Mode Simulator`；
2. `start-local-server.ps1`；
3. `manage.ps1 -Status` 并确认 `LocalTarget=SIMULATOR`、`DatabaseName=thyroid_local`；
4. 验证 `http://127.0.0.1:<PORT>/health` 返回 `status=ok`、`database=ok`；
5. 再进入开发者工具编译和 QA。

本地健康检查失败时排查本机进程、端口和私有配置，不得自动改连 `thyroid-ecs`。

## 真机同局域网

仍然使用本机服务和 `thyroid_local`，只改变手机到本机 API 的连接方式：

1. 在 `tools/env/local.env.ps1` 设置 `LOCAL_LAN_API_BASE_URL`；该值不进入 Git。
2. 执行 `manage.ps1 -Mode Lan`。
3. 使用 `start-local-server.ps1 -Access Lan` 启动本机服务，使 API 监听局域网接口；数据库门禁仍强制回环数据库和 `thyroid_local`。
4. 电脑和手机分别验证同一 `/health`，再重新编译并真机调试。
5. 如果 Windows 防火墙阻断，只在用户明确授权后新增仅允许局域网来源的临时规则。
6. 结束后切回 `Simulator`，并删除本次临时防火墙规则。

不要把个人电脑局域网地址写入可提交文件。

## 真机非局域网

项目保留现有 Cloudflare Quick Tunnel 方案，但改为受控工具入口：

```text
手机 → 临时 HTTPS 通道 → 本机 API → thyroid_local
```

- `cloudflared.exe` 只保存在被忽略的 `tools/env/bin/`，不提交二进制。
- 只有用户明确要求本次非局域网联调，并确认使用第三方开发通道时，Agent 才能传入 `-ConfirmRemoteTunnel`；这个参数不能由 Agent 自行当作授权。
- 工具启动前验证本机 `/health`，建立通道后再次验证通道 `/health`，成功后才修改小程序本地 API 地址。
- 启动失败会尝试恢复模拟器模式；测试结束必须执行 `-StopRemote`，确定性恢复 `localhost`，不恢复任意历史地址。
- 不开放 MySQL，不把本机数据库直接暴露到公网。默认使用合成或测试数据；若真实健康数据会经过第三方通道，先执行隐私影响判断。

## 生产 API 模式

生产模式只用于发布准备或用户明确要求的客户端切换：

- 必须显式使用 `-ConfirmProduction`；
- 工具只将小程序切到生产 HTTPS API，并恢复 `urlCheck=true`；
- 不访问生产数据库，不部署服务端，不上传微信代码，也不扩大任何生产授权；
- 发布完成后的普通开发应切回 `Simulator`。

## 私有配置与旧目录迁移

`tools/env/local.env.ps1.example` 是可提交模板；真实 `local.env.ps1` 被忽略。历史 `.local-server/` 只作为本机迁移来源，不再作为项目工具入口。迁移时保留本机秘密和数据库备份，公共脚本改用 `tools/env/`；旧的模式标记、隧道状态、生成 SQL 和无调用截图等运行时残留不迁入 Git。
